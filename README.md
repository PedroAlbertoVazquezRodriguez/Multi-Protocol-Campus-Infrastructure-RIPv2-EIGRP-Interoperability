# Multi-Protocol-Campus-Infrastructure-RIPv2-EIGRP-Interoperability
Diseño e implementación de una red de campus heterogénea con 6 sedes interconectadas en Cisco Packet Tracer. Interoperabilidad RIPv2 &lt;-> EIGRP mediante redistribución en un núcleo ASBR, VLSM, telefonía IP con SCCP/CME, hardening de seguridad y validación con 8 escenarios de prueba (L3-L7).
